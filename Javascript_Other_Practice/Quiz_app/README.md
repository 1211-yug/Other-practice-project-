# 📝 Simple Quiz App

Welcome to my **Simple Quiz App** Project.

Ye project maine **HTML, CSS aur Vanilla JavaScript** ka use karke banaya hai. Is project ka main purpose JavaScript concepts ko practically implement karna tha aur interactive web application banana tha.

---

## 🚀 About Project

Simple Quiz App ek interactive application hai jisme user multiple-choice questions solve kar sakta hai.

Har question ke 4 options hote hain.

User jab answer select karta hai to turant pata chal jata hai ki answer correct hai ya incorrect.

Quiz complete hone ke baad final score show hota hai.

Agar user ka score 5 ya usse zyada hota hai to celebration ke liye Confetti Animation bhi show hota hai.
